# پیاده‌سازی رابط کاربری صفحه اصلی علی‌بابا

این پروژه، پیاده‌سازی رابط کاربری صفحه اصلی سایت علی‌بابا است که با **React، Vite و Tailwind CSS** توسعه داده شده است.

هدف اصلی پروژه، پیاده‌سازی دقیق طراحی و توجه به جزئیات رابط کاربری مانند فاصله‌ها، اندازه‌ها، فونت‌ها، رنگ‌ها، سایه‌ها و چیدمان عناصر بوده است.

این پروژه کاملاً **Responsive** است و در اندازه‌های مختلف صفحه‌نمایش به‌درستی نمایش داده می‌شود.

> **توجه:** این پروژه یک بازسازی غیررسمی و صرفاً برای نمونه‌کار و اهداف آموزشی است و ارتباطی با شرکت علی‌بابا ندارد.

## تکنولوژی‌های استفاده‌شده

* React
* Vite
* Tailwind CSS
* JavaScript
* HTML
* CSS

## شروع پروژه

ابتدا وابستگی‌های پروژه را نصب کنید:

```bash
npm install
```

سپس سرور توسعه را اجرا کنید:

```bash
npm run dev
```

پس از اجرا، آدرس نمایش‌داده‌شده در ترمینال را در مرورگر باز کنید.

معمولاً پروژه روی آدرس زیر اجرا می‌شود:

```text
http://localhost:5173
```

## ویژگی‌ها

* پیاده‌سازی رابط کاربری صفحه اصلی علی‌بابا
* اجرای دقیق جزئیات UI
* طراحی کاملاً Responsive
* استفاده از کامپوننت‌های React
* استفاده از Tailwind CSS
* اجرای سریع با Vite

## ساخت نسخه Production

برای ساخت نسخه نهایی پروژه:

```bash
npm run build
```

برای مشاهده نسخه Production:

```bash
npm run preview
```

## هدف پروژه

این پروژه به عنوان یک **نمونه‌کار Front-End** ساخته شده و توانایی من در تبدیل طراحی به رابط کاربری واقعی و پیاده‌سازی دقیق جزئیات UI را نشان می‌دهد.
